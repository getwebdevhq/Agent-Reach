# New Niche Lead Structure Template

Follow this standardized folder system when onboarding a new lead generation niche:

`
leads/<Niche Name>/
├── niche.json                 # Niche metadata (name, country, artPreset, batches)
├── <niche>_all_leads.json     # Master JSON lead callset
├── <niche>_all_leads.csv      # Flat tabular export
├── <niche>_all_leads.xlsx     # Spreadsheet export
├── batches/                   # Individual harvested batches
└── outreach_templates.json    # High-converting pitch angles & templates
`
